# Dotfiles

## Summary

Personal configuration files organized by application so each tool's dotfiles can be managed and linked into `$HOME` independently (e.g., with GNU Stow).

## Subfolders

- `vim/` — Vim configuration (`.vimrc`) covering filetype detection, syntax highlighting, line numbers, and 2-space indentation.
- `wezterm/` — WezTerm terminal emulator configuration (`.wezterm.lua`) setting the font size and color scheme (`Edge Dark (base16)`).
